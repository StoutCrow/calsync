# Changelog

## 1.0.1
First published release. The 1.0.0 tag was pushed before the release workflow read the version number correctly, so no 1.0.0 release exists; the code is otherwise the same.

## 1.0.0
First public version. Written entirely by Claude (Anthropic) through Claude Code.

- Work, Personal (photo calendar and Immich hangouts), Describe and Calendar tabs
- Notion calendar view with month and list modes, hover cards, click-to-edit, drag to move
- Google Calendar: read-only iCal link, or sign in to edit and drag
- Readers: Gemini (with model fallback), Claude, local/Ollama
- Renamable, coloured tabs; Windows `.exe` with its own window and icon
- Home-server setup with Tailscale
- Update check and one-click update, 27 unit tests, release workflow
